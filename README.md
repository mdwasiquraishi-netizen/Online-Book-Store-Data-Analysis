# Online-Book-Store-Data-Analysis
## 1) Introduction
The Online Book Store Dashboard is an interactive Power BI data analytics and business intelligence project designed to analyze book sales, customers, orders, inventory, genres, authors, and geographical performance.
The dashboard converts raw online bookstore data into meaningful visual insights through multiple analytical pages:
1.Overview
2.Sales Analysis
3.Book Analysis
4.Customer Analysis
5.Geography Analysis
6.Insights
The project helps stakeholders understand sales performance, customer behavior, book and genre performance, inventory levels, monthly trends, and geographical sales distribution. Interactive slicers and page navigation allow users to explore the data dynamically.
